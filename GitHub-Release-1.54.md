# RICS 1.54

Hotfix released October 22, 2026 after testing.

RimWorld 1.6 and 1.7. Same RICS version on both.

This is the RimWorld 1.7 test build. The RimWorld 1.6 build is also RICS 1.54 for the Kick chat fix. The first unstable test loaded with no errors. Research Vote, Storyteller, and the chatbot addon started with it.

## Updated

- `!captolamia` tells the developer which RimWorld version and build is running.
- The lab coat category patch is skipped when Anomaly is not installed.

## Fixed

- Kick chat connects again. Kick replaced the public chat key on 13 October 2026. RICS asks Kick for the current key when it connects.
- Turning off pawn, event, weather, use, equip, or wear now tells chat that the sub-command is disabled.
- Bill details keeps Any worker and the allowed crafting skill. The Count owned row had made that window too short.
